# 📊 Smart Store Sales Dashboard

An interactive **Power BI** dashboard that analyzes Smart Store sales data from 2019–2020, covering sales, profit, orders, and shipping performance across regions.

![Dashboard](dashboard.png)

## 🎯 Objective
Help Smart Store understand **what sells, where it sells, and how profitable it is**, so it can make better decisions on products, regions, and shipping.

## 📈 Key Metrics (East region view)
| Metric | Value |
|--------|-------|
| Orders | 6,251 |
| Profit | 53K |
| Avg. Ship Days | 4 |

## 🔍 Dashboard Features
- **Region slicer** (Central, East, South, West) to filter the whole report
- **Monthly Sales & Profit YoY**: compares 2019 vs 2020 trends
- **Sales by Segment**: Consumer, Corporate, Home Office
- **Sales by Payment Mode**: COD, Online, Cards
- **Sales by Ship Mode**: Standard, First Class, Second Class, Same Day
- **Sales by Category & Sub-Category**: Office Supplies, Technology, Furniture
- **Map visual**: sales and profit by state
- **Sales forecast**: time-series view of daily sales with a forecast into Jan 2021

## 💡 Key Insights
- Sales and profit grew in **2020 compared to 2019**, with a peak in the second half of the year.
- **Consumer** is the largest segment (50%), followed by Corporate (31%).
- **COD** is the most-used payment mode (44%).
- **Standard Class** is the most-used shipping method.
- **Office Supplies** leads in sales, ahead of Technology and Furniture.
- **Phones, Chairs, and Binders** are the top sub-categories.

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (data cleaning)
- DAX (measures)
- Excel/CSV (data source)
